# Student Management System

## About

A Java-based Student Management System developed using Hibernate ORM for managing student records and database operations.

## Technologies Used

* Java
* Hibernate ORM
* MySQL (if configured in this project)

## Project Structure

* `HibernateConfig.java` – Hibernate configuration
* `Student.java` – Student entity
* `StudentDao.java` – Data access operations
* `StudentService.java` – Service-layer operations
* `StudentController.java` – Controller class
* `StudentManagementSystemApp.java` – Application entry point

## Features

* Student record management
* Database operations using Hibernate

## Setup

1. Clone or download this repository.
2. Configure your database credentials in the Hibernate configuration.
3. Create the required database in MySQL.
4. Open the project in your Java IDE and configure the required dependencies.
5. Run `StudentManagementSystemApp.java` if it is the application's entry point.
